 To-Do List Web App


This project allows users to:
- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by category or status


 Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- C#
- LINQ


 Features

✔ Create tasks  
✔ Update tasks  
✔ Delete tasks  
✔ Filter by category  
✔ Mark as completed  
✔ Clean UI with Bootstrap
